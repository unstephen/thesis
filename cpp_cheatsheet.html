1万能骨架（每题开头都抄这个）

#include <iostream>      // 搬进 cin/cout 的工具箱
using namespace std;     // 报名：后面不用写 std:: 姓氏

int main() {             // 程序大门，从这里开始执行

    return 0;            // 程序正常结束（体检合格）
}                        // 和 main 的 { 配对
✏️ 踩坑史：usin→using、namspace→namespace、reture→return。关键词是固定咒语，错一个字母编译器就不认识，它不会像老师一样猜你的意思。

2输入输出

int x;
cin >> x;                // 读入：箭头朝变量「装进去」
cout << x << endl;       // 输出：箭头朝外「倒出来」，endl 换行
cout << x << " " << y;   // 两个数中间加空格
🧠 记忆锚点：cin >> 箭头指向变量 = 往里装；cout << 箭头背对变量 = 往外倒。

3常用类型（选装数据的盒子）

int x;           // 整数，装到约 21 亿
long long x;     // 大整数，装到约 922 亿亿（数据大就用它）
double x;        // 小数
char c;          // 单个字符，如 'A'
bool flag;       // 真 / 假，只有 true 和 false
✅ 已掌握：数据超过 21 亿要换 long long（llabs 那题已经用对了）。

4运算符

a + b    a - b    a * b    a / b      // 加减乘除（整数除法舍小数：7/2=3）
a % b                                 // 取余数：7%2=1（判断整除全靠它）
a == b                               // 等于（两个等号！）
a != b                               // 不等于（连体婴，中间无空格）
a > b    a < b    a >= b    a <= b   // 比较
&&                                   // 并且（两边都真才真）
||                                   // 或者（一边真就真）
!                                    // 取反
✏️ 踩坑史：! 和 = 中间加了空格就拆成两个东西，编译器直接懵。== 是问句（相等吗？），= 是赋值（把右边塞给左边）。
🎯 自测：闰年判断那条条件怎么写？（点下方看答案）
查看答案

y % 400 == 0 || (y % 4 == 0 && y % 100 != 0) —— 能被400整除，或者能被4整除但不能被100整除。

5判断

if (条件) {               // 条件为真走这里
    ...
} else if (另一个条件) {   // 上面的不真才来问这个
    ...
} else {                  // 全都不真走这里
    ...
}
🧠 范例：你的闰年程序就是标准 if-else 结构，逻辑完全正确，只输在拼写。

6常用工具函数

代码作用要搬的工具箱
abs(x)int 绝对值<cstdlib>
llabs(x)long long 绝对值<cstdlib> ✅用过
fabs(x)小数绝对值<cmath>
sqrt(x)开平方<cmath>
pow(a, b)a 的 b 次方<cmath>
max(a, b)两数取大<algorithm>
min(a, b)两数取小<algorithm>
swap(a, b)交换两数<algorithm>
🧠 工具箱逻辑：函数不住在程序里，要用谁就得先 #include 把它家的工具箱搬进来——就像 llabs 住在 <cstdlib> 里。

7循环（提前预告，后面会练）

for (int i = 0; i < n; i++) {   // 从 0 数到 n-1，共 n 圈
    ...
}
while (条件) {                   // 条件为真就一直转
    ...
}
🧠 for 三件套：起点（int i = 0）→ 终点条件（i < n）→ 步子（i++，每次加1）。
🎯 自测：想输出 1~100 所有数，for 括号里三件套怎么写？
查看答案

for (int i = 1; i <= 100; i++) —— 从 1 出发，数到 100 为止，每步加 1。
